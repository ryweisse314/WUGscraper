# WUGscraper
Tool that automatically grabs monthly data from Weather Underground.

To use, follow these steps:

1. Clone this repo to desktop. (optional)
2. Open the WUGscraper folder. 
3. Double-click the setup.bat file and let it run to completion.
4. Double-click the launch.bat file.
5. The command prompt should direct you to a webpage after a few seconds, go to that site. 
6. Use the dropdown to select the site you want to fetch weather data for.
7. Click the "Load available columns" button to see what filters you can put on the data before scraping. 
8. Select which filters you want to keep.
9. Click the "Run scrape" button and wait around 1 minute.
10. Your .csv file will be downloadable, which from that point can be viewed in Excel.
11. If you have any problems, send me a Teams message and I can try to help you.
